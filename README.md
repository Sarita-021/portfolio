## Installation (for local development)

If you'd like to run this portfolio website locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Sarita-021/portfolio.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd portfolio
    ```
3.  **Install dependencies (if applicable, e.g., for a React or Node.js project):**
    ```bash
    npm install  # or yarn install
    ```
4.  **Run the development server (if applicable):**
    ```bash
    npm start  app.js
    ```
5.  Open your browser and navigate to `http://localhost:3000`.
